# Once UI 2.0 | Dark - Fejlesztői Implementációs Útmutató

## 📚 Bevezetés

A **Once UI 2.0** design rendszer **Dark** témája egy modern, konzisztens és felhasználóbarát felületet biztosít alkalmazásaink számára. Ez az útmutató segít a fejlesztőknek a design rendszer pontos implementálásában, a Figma tervektől a működő React komponensekig.

🔗 **Figma referencia:** [Once UI 2.0 | Dark prototípus](https://www.figma.com/proto/yvUdwkEmnjKpxFzieIjNFg/Once-UI-2.0-%7C-Dark)

## 🎯 Alapelvek

- **Konzisztencia:** Egységes megjelenés és viselkedés az egész alkalmazásban
- **Tisztaság és Olvashatóság:** Optimális kontrasztarányok, letisztult elrendezés
- **Modularitás:** Újrafelhasználható komponensek a fejlesztés gyorsítására
- **Visszajelzés:** Interakciók és rendszerállapotok egyértelmű kommunikálása

## 🧩 Komponensek

### Gombok (Buttons)

#### Variánsok

- **Primary Button**: Fő akciókhoz, kék háttérrel és fehér szöveggel
- **Secondary Button**: Másodlagos akciókhoz, lila/magenta háttérrel
- **Tertiary/Text Button**: Kevésbé hangsúlyos akciókhoz, háttér nélkül
- **Outline Button**: Keretes gomb háttér nélkül
- **Icon Button**: Csak ikont tartalmazó gomb

#### Méretek

- **Small**: Kompakt méret (pl. kis területeken)
- **Medium**: Alapértelmezett méret
- **Large**: Kiemelt akciókhoz

#### Állapotok

Minden variánsnak definiált állapotai:
- **Default**: Alap megjelenés
- **Hover**: Egér felette (világosabb árnyalat)
- **Active/Pressed**: Megnyomott állapot (sötétebb árnyalat)
- **Focus**: Billentyűzettel fókuszált (kék keret)
- **Disabled**: Inaktív állapot (szürke, alacsony kontraszt)

#### React implementáció

```jsx
// Button.jsx
import React from 'react';
import './Button.css';
import classNames from 'classnames';

const Button = ({
  children,
  variant = 'primary',
  size = 'medium',
  disabled = false,
  iconLeft,
  iconRight,
  onClick,
  className,
  ...props
}) => {
  const buttonClasses = classNames(
    'once-button',
    `once-button--${variant}`,
    `once-button--${size}`,
    { 'once-button--disabled': disabled },
    className
  );

  return (
    <button
      className={buttonClasses}
      disabled={disabled}
      onClick={onClick}
      {...props}
    >
      {iconLeft && <span className="once-button__icon--left">{iconLeft}</span>}
      <span className="once-button__text">{children}</span>
      {iconRight && <span className="once-button__icon--right">{iconRight}</span>}
    </button>
  );
};

export default Button;
```

### Űrlapelemek (Forms)

#### Text Input

```jsx
// TextInput.jsx
import React from 'react';
import './TextInput.css';
import classNames from 'classnames';

const TextInput = ({
  label,
  id,
  value,
  onChange,
  placeholder,
  disabled = false,
  error,
  helperText,
  icon,
  className,
  ...props
}) => {
  const inputWrapperClasses = classNames(
    'once-input-wrapper',
    { 'once-input-wrapper--error': error },
    { 'once-input-wrapper--disabled': disabled },
    className
  );

  return (
    <div className={inputWrapperClasses}>
      {label && (
        <label htmlFor={id} className="once-input__label">
          {label}
        </label>
      )}
      <div className="once-input__container">
        <input
          id={id}
          value={value}
          onChange={onChange}
          disabled={disabled}
          placeholder={placeholder}
          className="once-input"
          {...props}
        />
        {icon && <span className="once-input__icon">{icon}</span>}
      </div>
      {(helperText || error) && (
        <p className={`once-input__helper-text ${error ? 'once-input__helper-text--error' : ''}`}>
          {error || helperText}
        </p>
      )}
    </div>
  );
};

export default TextInput;
```

## 🧠 Legjobb gyakorlatok

### 1. Design Tokenek konzisztens használata

```jsx
// ❌ KERÜLENDŐ
<div style={{ padding: '8px', backgroundColor: '#1F2937', borderRadius: '8px' }}>...</div>

// ✅ HELYES
<div style={{ 
  padding: 'var(--spacing-2)', 
  backgroundColor: 'var(--color-bg-card)', 
  borderRadius: 'var(--radius-md)' 
}}>...</div>
```

### 2. Komponensek újrafelhasználása

```jsx
// ❌ KERÜLENDŐ
<button className="custom-button" onClick={handleClick}>
  Kattints ide
</button>

// ✅ HELYES
import { Button } from '../components/Button';

<Button variant="primary" onClick={handleClick}>
  Kattints ide
</Button>
```

### 3. Reszponzív tervezés

```css
/* A 12 oszlopos grid rendszer használata (pl. CSS Grid-del) */
.container {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: var(--spacing-4);
}

/* Reszponzív töréspontok */
@media (max-width: 768px) {
  .card {
    grid-column: span 6; /* Tablet nézet */
  }
}

@media (max-width: 480px) {
  .card {
    grid-column: span 12; /* Mobil nézet */
  }
}
```

### 4. Hozzáférhetőség (Accessibility)

```jsx
// Mindig használj szemantikus HTML elemeket megfelelő ARIA attribútumokkal
<button 
  aria-label="Bezárás" 
  aria-describedby="closeDescription"

</button>
<div id="closeDescription" className="sr-only">
  Bezárja a jelenlegi ablakot
</div>
```

## 🔧 React-ba történő integráció lépései

1. **Telepítsd a függőségeket**
   ```bash
   npm install classnames  # Class nevek egyszerű kezelése
   ```

2. **Design tokenek beállítása**
   - Hozz létre egy `tokens.css` fájlt a design tokenek (színek, betűméretek, stb.) definiálásával
   - Importáld a fő CSS fájlodban vagy közvetlenül az alkalmazás belépési pontjában

3. **Komponensek létrehozása**
   - Készíts egy külön mappát a komponenseknek (`/src/components`)
   - Minden komponens saját mappában legyen a stílussal és dokumentációval együtt
   - Használj storybook-ot, ha lehetséges, a komponensek dokumentálására

4. **Exportáld a komponenseket**
   - Hozz létre egy index.js fájlt, amely exportálja az összes komponenst
   ```javascript
   // src/components/index.js
   export { default as Button } from './Button/Button';
   export { default as TextInput } from './TextInput/TextInput';
   // további komponensek...
   ```

5. **Használat alkalmazásokban**
   ```jsx
   import { Button, TextInput } from './components';
   
   function LoginForm() {
     return (
       <div className="login-form">
         <h2>Bejelentkezés</h2>
         <TextInput label="Email" placeholder="emailcímed@példa.hu" />
         <TextInput label="Jelszó" type="password" placeholder="********" />
         <Button variant="primary">Bejelentkezés</Button>
       </div>
     );
   }
   ```

## 👨‍💻 Fejlesztői tippek

- Használj CSS pre-processzort (SASS/LESS) vagy CSS-in-JS megoldást (Styled Components, Emotion) a komplexebb komponenseknél
- Tartsd szem előtt a "mobile-first" megközelítést
- Használj CSS zmódosító osztályokat (BEM módszertan) az állapotok kezelésére
- Az ikonokat SVG-ként implementáld a jobb skálázhatóság érdekében
- Dokumentáld a komponenseket és azok variánsait, állapotait
