Rendben, nézzük meg, hogyan implementálhatjuk a "Once UI 2.0 | Dark" design rendszert Reactban, TypeScripttel, a megadott szempontok alapján. A példákban a CSS Modules stratégiát fogom használni CSS változókkal, mivel ez jól elkülöníti a stílusokat, scope-olja őket, és közvetlenül használja a kért CSS változókat.

Fontos megjegyzés: Mivel nem tudok közvetlenül interakcióba lépni a Figma fájllal és kinyerni a pontos hex kódokat, méreteket stb., az alábbi kódrészletek reprezentatív értékeket használnak a Figmában látott vizuális stílus alapján. A pontos értékeket (színek, méretek, árnyékok stb.) neked kell majd kinyerned a Figma Inspect paneljéből és behelyettesítened a CSS változókba!

1. Styling Stratégia és Design Tokenek Implementációja

Stratégia: CSS Modules + CSS Custom Properties (Variables).

CSS Modules: Minden komponens saját .module.css fájlt kap, ami automatikusan scope-olja a class neveket, elkerülve a globális névütközéseket.

CSS Custom Properties: A design tokeneket (színek, spacing, stb.) globálisan definiáljuk CSS változókban, amelyeket a komponensek stílusai újrahasználnak.

import React, { forwardRef, ReactNode } from 'react';
import classnames from 'classnames'; // npm install classnames @types/classnames
import styles from './Button.module.css';

// Props definíciója TypeScript interfésszel
export interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'outline' | 'text' | 'iconOnly';
  size?: 'sm' | 'md' | 'lg';
  iconLeft?: ReactNode;
  iconRight?: ReactNode;
  children?: ReactNode; // Kell, ha nem iconOnly
  className?: string;   // Külső class nevek fogadására
}

export const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  (
    {
      variant = 'primary',
      size = 'md',
      iconLeft,
      iconRight,
      children,
      className,
      disabled,
      type = 'button', // Alapértelmezett type
      ...props // Minden más HTML button attribútum (pl. onClick)
    },
    ref
  ) => {
    const buttonClasses = classnames(
      styles.button,
      styles[variant], // pl. styles.primary
      styles[`size-${size}`], // pl. styles['size-md']
      {
        [styles.iconOnly]: variant === 'iconOnly' || (!children && (iconLeft || iconRight)),
        [styles.hasIconLeft]: !!iconLeft,
        [styles.hasIconRight]: !!iconRight,
        [styles.disabled]: disabled, // Bár a :disabled is működik, explicit class hasznos lehet
      },
      className // Külső class nevek
    );

    // ARIA: Icon-only gombokhoz kell aria-label
    const ariaLabel = variant === 'iconOnly' ? props['aria-label'] || 'Button' : undefined;
    if (variant === 'iconOnly' && !ariaLabel && process.env.NODE_ENV === 'development') {
        console.warn('IconOnly Button requires an aria-label prop for accessibility.');
    }

    return (
      <button
        ref={ref}
        className={buttonClasses}
        type={type}
        disabled={disabled}
        aria-disabled={disabled} // Explicit ARIA attribútum
        aria-label={ariaLabel}
        {...props}
      >
        {iconLeft && <span className={styles.iconWrapper}>{iconLeft}</span>}
        {/* IconOnly esetén a children nem jelenik meg explicit */}
        {variant !== 'iconOnly' && children && <span>{children}</span>}
        {iconRight && <span className={styles.iconWrapper}>{iconRight}</span>}
      </button>
    );
  }
);

Button.displayName = 'Button'; // Jó gyakorlat forwardRef esetén

import React, { forwardRef, useId, ReactNode } from 'react';
import classnames from 'classnames';
import styles from './TextInput.module.css';

// Props
export interface TextInputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  label?: string;
  hideLabel?: boolean; // Ha vizuálisan rejtett, de ARIA számára elérhető kell legyen
  helperText?: string;
  error?: string | boolean; // Hibaüzenet vagy csak jelzés
  iconLeft?: ReactNode;
  iconRight?: ReactNode;
  containerClassName?: string; // A külső wrapper div classa
}

export const TextInput = forwardRef<HTMLInputElement, TextInputProps>(
  (
    {
      label,
      hideLabel = false,
      id,
      helperText,
      error,
      iconLeft,
      iconRight,
      className, // Az input elem classa
      containerClassName,
      disabled,
      required,
      ...props // Minden más HTML input attribútum (pl. value, onChange, name, type='text'/'email'/'password' etc.)
    },
    ref
  ) => {
    const generatedId = useId(); // Automatikus ID generálása, ha nincs megadva
    const inputId = id || generatedId;
    const hasError = !!error;
    const helperTextId = helperText ? `${inputId}-helper` : undefined;
    const errorTextId = hasError && typeof error === 'string' ? `${inputId}-error` : undefined;

    // ARIA: Input leírása helper vagy error texttel
    const describedBy = [helperTextId, errorTextId].filter(Boolean).join(' ') || undefined;

    const containerClasses = classnames(
      styles.container,
      {
        [styles.hasError]: hasError,
        [styles.disabled]: disabled,
      },
      containerClassName
    );

    const inputWrapperClasses = classnames(
      styles.inputWrapper,
      {
        [styles.hasIconLeft]: !!iconLeft,
        [styles.hasIconRight]: !!iconRight,
      }
    );

    const inputClasses = classnames(
      styles.input,
      className // Külső class nevek az inputra
    );

    const labelClasses = classnames(
        styles.label,
        { [styles.visuallyHidden]: hideLabel }
    );

    return (
      <div className={containerClasses}>
        {label && (
          <label htmlFor={inputId} className={labelClasses}>
            {label} {required && <span aria-hidden="true">*</span>}
          </label>
        )}
        <div className={inputWrapperClasses}>
          {iconLeft && <span className={classnames(styles.icon, styles.iconLeft)}>{iconLeft}</span>}
          <input
            ref={ref}
            id={inputId}
            className={inputClasses}
            disabled={disabled}
            required={required}
            aria-invalid={hasError ? 'true' : 'false'}
            aria-describedby={describedBy}
            aria-required={required}
            {...props} // Pl. type, value, onChange, placeholder
          />
          {iconRight && <span className={classnames(styles.icon, styles.iconRight)}>{iconRight}</span>}
        </div>
        {/* Helper text VAGY Error text jelenik meg */}
        {!hasError && helperText && (
          <p id={helperTextId} className={styles.helperText}>
            {helperText}
          </p>
        )}
        {hasError && typeof error === 'string' && (
          <p id={errorTextId} className={styles.errorText} role="alert">
            {error}
          </p>
        )}
      </div>
    );
  }
);

## 4. További Komponensek Implementálása

A többi kért komponenst (Textarea, Select, Checkbox, Radio, Toggle, Card, Modal, Tabs, Breadcrumbs, Pagination, Alert, Toast, Progress) hasonló elvek mentén kell implementálni:

1.  **Atomic Design:** Határozd meg, hogy atom (`Checkbox`, `Radio`), molekula (`TextInput` labellel, `Alert` ikonnal és szöveggel) vagy organizmus (`Card` képpel, címmel, szöveggel, gombokkal; `Modal` fejléccel, tartalommal, lábléccel).
2.  **Props:** Definiáld a szükséges TypeScript propokat a variációkhoz, állapotokhoz és tartalomhoz.
3.  **Markup (TSX):** Hozd létre a megfelelő HTML struktúrát, ügyelve a szemantikára és az ARIA attribútumokra (pl. `role`, `aria-checked`, `aria-labelledby`, `aria-describedby`, `aria-modal`).
4.  **Styling (CSS Modules):** Hozd létre a `.module.css` fájlt, használd a CSS változókat a tokenekből, definiáld a variánsokat és állapotokat osztályokkal és pszeudo-osztályokkal (`:hover`, `:focus-visible`, stb.).
5.  **Accessibility:** Különösen figyelj a form elemeknél a `label`-`input` összekapcsolásra (`htmlFor`/`id`), a modal-oknál a focus trapping-re és az `aria-modal="true"` használatára, a tab-oknál a `role="tablist/tab/tabpanel"` és az `aria-selected` attribútumokra.
6.  **Reszponzivitás:** Használj media query-ket a CSS Modules fájlokban, ha a komponensnek eltérően kell viselkednie különböző képernyőméreteken (pl. Card elrendezése). A 12 oszlopos gridet magasabb szintű layout komponensekben vagy a lapok szerkezetében használd.

## 5. Hozzáférhetőség (Accessibility)

Ez kulcsfontosságú:

*   **Szemantikus HTML:** Mindig a megfelelő HTML elemet használd (pl. `<button>`, `<nav>`, `<input type="checkbox">`).
*   **Billentyűzet Navigáció:** Biztosítsd, hogy minden interaktív elem elérhető és kezelhető legyen billentyűzettel. Használd a `:focus-visible` pseudó-osztályt a látható focus jelzéshez.
*   **ARIA Attribútumok:** Használd őket helyesen, ahol a natív HTML nem elegendő (pl. `aria-label` icon-only gomboknál, `aria-invalid` hibás inputoknál, `role` komplexebb widgeteknél mint Tabs, Modal).
*   **Színkontraszt:** **Ellenőrizd a Figmában megadott színek kontrasztarányát** a WCAG AA szint követelményeinek megfelelően, különösen szöveg és háttér között. Használj online kontrasztellenőrző eszközöket.
*   **Form Címkék:** Minden form elemhez tartozzon látható vagy vizuálisan rejtett (`visuallyHidden` class) `<label>`.
